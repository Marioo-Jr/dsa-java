# Índice: Problema → Vídeo

A playlist do [Nick White](https://www.youtube.com/playlist?list=PLU_sdQYzUj2keVENTP0a5rdykRSgg9Wp-)
tem 189 vídeos ordenados por **data de upload**, não por tópico, e cobre boa parte — mas
não tudo — dos 150 problemas da NeetCode 150. Fiz uma varredura completa da playlist
(scroll até o fim, os 189 títulos) e cruzei com a lista oficial em
[neetcode.io/practice/practice/neetcode150](https://neetcode.io/practice/practice/neetcode150).

**Como os links funcionam**: em vez de um `watch?v=...` fixo (que quebra se o vídeo sair
do ar), cada linha usa uma busca no YouTube restrita ao Nick White — o vídeo certo é
quase sempre o primeiro resultado, e o link não quebra. Isso também significa que, mesmo
numa linha marcada ✅, vale conferir se o primeiro resultado é mesmo o vídeo certo.

**Quando o Nick White não cobre** (marcado com ⚠️), a ordem de fallback é:
1. [neetcode.io/practice](https://neetcode.io/practice) — filtrar a solução por Java.
2. Vídeo do próprio NeetCode no YouTube (em Python — traduzir para Java é parte do exercício).
3. Aba "Solutions" do próprio problema no LeetCode, filtrando por Java.

⚠️ é uma marca de "não vi na varredura", não uma certeza absoluta — a playlist tem 189
vídeos e é fácil um título passar despercebido no scroll. Se encontrar um vídeo dele para
um problema marcado ⚠️, o link de busca no topo de cada tabela já resolve.
